# 为什么 P vs NP 如此之难 — 三重屏障

> 相对化、自然化、代数化：一份带完整推导的技术导论

五十多年来，P vs NP 既没有被证明，也没有被否证，连「证明它很难」这件事本身都已经被严格地做了一遍。答案不是聪明人不够多，而是三条已证明的定理分别排除了三类数学技术。

| 屏障 | 年份 | 排除的技术 | 核心原因 |
|---|---|---|---|
| 相对化 | 1975 | 模拟 + 对角线法 | 存在矛盾的预言机世界 |
| 自然化 | 1997 | 组合式电路下界技术 | 与伪随机性不相容 |
| 代数化 | 2008 | 算术化技术 | 存在矛盾的代数预言机世界 |

这三条屏障是叠加的，不是并列的：一个有效的证明必须同时击穿全部三条。合起来，它们把可行的方法空间压缩到了一个至今无人知道是否非空的程度。
